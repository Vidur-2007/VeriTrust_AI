# VeriTrust AI frontend

The React app: customer site, ops console, dashboard and the other pages. Setup, architecture and
the demo script are in the [main README](../README.md); the design rules are in
[docs/DESIGN.md](../docs/DESIGN.md).

```bash
npm install
npm run dev      # http://localhost:5173, expects the backend on port 8000
npm test         # vitest
npm run lint
npm run build
```
